# Data provenance

Where every input dataset comes from, how it was made, what has been changed
since, and which official source is meant to replace it. The datasets are
**research-grade**: credible, structured for the model, and traceable — but not
yet drawn from official published sources. This file is the traceability record;
the upgrade path to decision-grade data is the replacement map at the bottom.

*Every claim here is checkable: lineage via `git log --follow <file>`,
byte-identity via `cmp`, flag consistency via `tools/validate_schema.py`.*

## Lineage in one paragraph

Everything descends from the repository's initial snapshot (commit `42c222f`),
a fork of **`village-indonesia-100gw@1096aa4`** — the IESR / UC San Diego Power
Transformation Lab study behind Indonesia's 100 GW village-solar programme. The
**grid-side files are byte-identical to the
[Power-Lab/data-indonesia-2025](https://github.com/Power-Lab/data-indonesia-2025)
release** (MIT; the data behind the captive-indonesia-2025 study,
[report on Zenodo](https://zenodo.org/records/17345968)) — verified by `cmp`
across every shared grid file for all seven overlapping islands in both years.
Since the snapshot, this repository has made three classes of data change, each
listed in the modification log below: RE-flag corrections, hubdist-based
connection costs, and the synthetic demo case.

## Known quirks (documented, deliberately not "fixed")

- **maluku `plts_buia` appears twice** (upstream naming): R_ID 16 is a genuine
  5 MW solar unit (solar CF profile, mean 0.14); R_ID 17 is a 3 MW **gas engine**
  carrying a solar-style name (flat availability, gas fuel, gas-engine costs).
  The audit corrected R_ID 17's RE flag; the misleading name is left as imported
  so the row remains traceable to upstream.
- **`Sub_Weights` are non-uniform for maluku** (2022/505/…), so representative-
  period energy sums annualise only approximately there — see the note in
  [`docs/outputs_guide.md`](../docs/outputs_guide.md).
- **Fuel prices and technology costs** are the upstream study's assumptions
  (`fuels_data.csv`, generator cost columns) and have not been revalidated here.
  NTT-specific cost assumptions used for the Timor build are in
  [`tools/ntt/costs.py`](../tools/ntt/costs.py), each overridable.

## Replacement map: research-grade → decision-grade

The concept note's Phase 2 replaces these inputs island-by-island. What replaces
what:

| Input | Official source to substitute |
|---|---|
| `generators.csv` (fleet, candidates, costs) | **PLN RUPTL** project lists + published technology cost benchmarks |
| `network.csv` (inter-zonal limits) | **PLN RUPTL** transmission plan |
| `demand.csv` (zonal demand, growth) | **ESDM / RUKN** demand projections |
| `village_demand.csv` + electrification status | **BPS Podes** / PLN electrification data + partner surveys (the NTT workbooks are the template) |
| `fuels_data.csv` (prices, emission factors) | **ESDM** fuel price benchmarks; IPCC emission factors |
| `village_connection.csv` unit costs | **PLN** MV-line and connection unit costs (flags on `tools/connection_cost.py`) |

The schema is unchanged by substitution: drop replacement CSVs into a folder and
`tools/validate_schema.py` + `run_model.jl --preflight-only` will gate them.
